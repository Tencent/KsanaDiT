# Models

Model wrappers for diffusion models, text encoders, and VAEs.

## Overview

- [`ModelKey`](model_key.md) — Model type identification via filename pattern matching
- [`ModelPool`](model_pool.md) — Model instance management
- [`DiffusionModel`](diffusion_model.md) — Diffusion model wrappers (Wan, Qwen, VACE)
- [`TextEncoderModel`](text_encoder_model.md) — Text encoder wrappers
- [`VAEModel`](vae_model.md) — VAE model wrappers
