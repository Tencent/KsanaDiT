# Pipeline

The Pipeline module provides the declarative pipeline system for defining and executing inference workflows.

## Overview

- [`Pipeline`](pipeline.md) — Main entry point via `Pipeline.from_models()`
- [`PipelineDef`](pipeline_def.md) — Immutable pipeline definition data structure
- [`ContextBuilder`](context_builder.md) — Strategy class for building `NodeContext`
- [`PipelineKey`](pipeline_key.md) — Pipeline type identification
